“does Jev understand colour?” — an unofficial recreation

His idea, his colours. Matt DesLauriers — @mattdesl on X, mattdesl on GitHub — posted this on 18 September 2026 and said how it worked: sixteen predefined colours, "just rendering their weighted probabilities". He linked no source, so I built a version that lives on a page you can type into. The sixteen colours are his too, from docs/palette.md in Bitframes.

Type a word. It goes to Jev, TypeSafe AI's System One model, as one typed question with sixteen options. Jev cannot write a word back: it returns a probability for each one. The bar is those probabilities, widest first. Hover a band to see which colour it is and what it got.

Built for fun by Paul Zammit, alongside Forma. Code: github.com/LamplighterPaul/jev-colour.
